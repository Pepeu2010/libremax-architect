# Marca LibreMax

`libremax-mark.png`: símbolo original solicitado à ferramenta de geração de imagem integrada do Codex em 01/10/2026, fundo transparente. Nenhuma imagem de marca externa foi usada como referência. O símbolo é distribuído junto com o projeto LibreMax.

Prompt usado:

> Create a polished original logo SYMBOL ONLY for LibreMax Architect, an open source native interior architecture application. Brand values: approachable precision, modern home design, creative freedom. One centered geometric architectural monogram combining L and M through an open room / folded floor-plan silhouette, strong instantly legible silhouette, clean precise edges, premium restrained design, flat violet (#A49AFF) and warm copper (#EBB48A) accents, light ivory optional only small highlights. It must work on dark charcoal UI and at small app icon sizes. Transparent background, generous clear space, no text, no lettering beyond the abstract LM symbol, no slogan, no mockup, no shadows, no gradients, no glow, no decorative background, no competing variants, no perspective product scene. Single finished production logo mark.

`apartment-preview.png`: render real 960×540/64 samples do `examples/apartamento-moderno.lmx`, Blender 5.2.1 LTS/Cycles CPU. É a imagem de exemplo da tela inicial. Modelos e mapas têm procedência documentada em `starter-models` e `starter-materials`; não é uma fotografia ou um render promocional da Poly Haven.
