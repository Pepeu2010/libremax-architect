# Instalar o LibreMax Architect

Escolha seu sistema. Os arquivos para baixar ficam nas [Releases do projeto](https://github.com/Pepeu2010/libremax-architect/releases). O repositório é público. Os instaladores publicados podem ser baixados sem acesso especial ao projeto.

| Sistema | Instalador | Guia |
|---|---|---|
| Windows 64 bits | `LibreMax-Architect-0.16.0-Windows-x64-Setup.exe` | [Windows](windows/README.md) |
| Ubuntu 24.04 / Linux Mint 22, 64 bits | `LibreMax-Architect-0.16.0-Linux-Ubuntu24.04-amd64.deb` | [Linux](linux/README.md) |

Esta é uma **prévia em desenvolvimento**. Modelos, texturas, tutorial, exemplos e Blender 4.5.9 LTS/Cycles acompanham o aplicativo. O render fica configurado automaticamente e funciona em segundo plano. [Dependências incluídas](../docs/BUNDLED_RUNTIME.md).

Os binários ficam nas Releases; estas pastas contêm instruções e a configuração de empacotamento. [Notas da prévia](RELEASE_NOTES.md). [Reproduzir os instaladores](../docs/BUILDING.md).
