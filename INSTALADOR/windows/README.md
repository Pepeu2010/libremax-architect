# Windows

1. Abra a [Release dos instaladores](https://github.com/Pepeu2010/libremax-architect/releases/tag/v0.9.0-rc.1).
2. Baixe **LibreMax-Architect-0.9.0-Windows-x64-Setup.exe**.
3. Abra o arquivo e siga o instalador em português.
4. Use **LibreMax Architect** no menu Iniciar ou na Área de Trabalho.

A instalação é feita para seu usuário. Não precisa instalar Qt, OpenCASCADE, Python ou ferramentas de programação. Catálogo e exemplos já estão incluídos.

Na primeira abertura, siga o tutorial ou escolha **Experimentar apartamento**. Salve seus projetos pelo menu Arquivo, em arquivos `.lmx`.

Para desinstalar, abra Aplicativos nas configurações do Windows e procure LibreMax Architect. Seus projetos e preferências são preservados. Evite guardar projetos dentro das pastas `bin` e `share` do aplicativo.

Esta prévia ainda não possui assinatura digital. O Windows pode mostrar um aviso de editor desconhecido. A compatibilidade é validada no Windows deste desenvolvimento e no runner Windows Server 2022; outras versões e configurações gráficas ainda precisam de testes.

Para fotos realistas, o Blender 5.2 LTS+ é uma instalação separada. Selecione o executável no painel Render; não é necessário abrir o projeto no Blender.
